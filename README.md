# Fredo AutoTarget

Auto-cible universelle pour WoW 1.12 (Turtle WoW / OctoWow). / Universal auto-target for WoW 1.12.

Pour chaque sort de ta liste, l'addon choisit la cible selon des filtres (en combat, a portee, sans mob controle / familier / tape / hors de vue) et 9 modes : garder, a portee, plus proche, assister, prioritaire, plus faible, lanceur, soigner, aucun. Puis il lance le sort et l'auto-attaque.

For each spell on your list, the addon picks the target using filters (in combat, in range, not crowd-controlled / pet / tapped / out of line of sight) and 9 modes: keep, in range, nearest, assist, priority, weakest, caster, heal, none. Then it casts and auto-attacks.

## Installation
Copie le dossier `FredoAutoTarget` dans `Interface/AddOns/` (le dossier doit s'appeler exactement `FredoAutoTarget`). / Put the folder in `Interface/AddOns/`, named exactly `FredoAutoTarget`.

## Utilisation / Usage
- `/fat` : ouvre le menu / opens the options window
- `/fat help` : liste des commandes / command list
- `/fat lang auto|fr|en` : langue / language
- Presets de classe, profils par specialisation, export/import (FAT2).
